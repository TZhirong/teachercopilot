# 高校备课助手 · Faculty Prep Copilot

> 面向高校教师的一站式 AI 备课助手：把一份「课程画像」变成知识图谱、教案、课件、试卷和作业反馈。

## 一句话定位

教师只填一次课程信息，即可用 AI 流式生成五个环节的**结构化教学成果**，并一键导出为可直接使用的文件——把备课从「从零开始写」变成「生成后二次编辑」。

## 解决什么问题

| 教师的痛点 | 本产品的解法 |
| --- | --- |
| 备课环节多、重复劳动 | 一次课程画像，五个模块共享，避免反复填 |
| AI 输出是「一大段文字」，难落地 | artifact-v1 结构化成果，可预览、可编辑、可导出 |
| 生成过程不透明 | 流式输出实时可见，可随时**停止 / 重试** |
| 成果格式杂乱 | 一键导出 SVG / HTML / DOCX / PPTX / 学生卷 / 教师卷 / Markdown / Word / ZIP |
| 担心密钥与数据安全 | 支持**自带 Key（BYOK）**，密钥只存本地浏览器，不上传其它服务器 |

## 目标用户与场景

- **高校教师 / 青年教师**：日常备课、公开课、教学设计、命题、作业讲评
- **教研团队**：统一产出规范、共享课程画像

典型链路：知识点梳理 → 教案设计 → 课件大纲 → 试题组卷 → 作业反馈。

## 核心能力（五大模块）

| 模块 | 解决什么问题 | 主要产出 |
| --- | --- | --- |
| 01 知识点梳理 | 厘清知识结构与先修关系 | 交互知识图谱、重难点、易错点、课堂活动 |
| 02 教案设计 | 快速产出可执行的教学流程 | 目标、重难点、师生活动、评价、板书 |
| 03 课件大纲 | 把内容变成授课节奏 | 页纲、要点、案例、互动、讲稿 |
| 04 试题组卷 | 按目的 / 难度 / 题型命制试卷 | 蓝图、题目、解析、覆盖矩阵 |
| 05 作业反馈 | 面向班级讲评的反馈闭环 | 量规、班级诊断、分层反馈、行动清单 |

## 使用流程

1. 填写**课程画像**（课程名、主题、学时、目标等，只填一次）
2. 选择要生成的**模块**
3. 补充模块化要求（课件方向/风格、试题目的/题量/难度等）
4. 点击**生成**，流式查看结果，可停止、可重试
5. **复制 Markdown** 或**导出**为需要的格式

## 产品亮点

- **一次填写，五模块共享**：课程画像全局复用，切换模块不丢配置
- **结构化成果**：模型输出统一为 artifact-v1 协议，前端稳定解析与预览
- **流式反馈**：空态 / 生成中 / 可停止 / 成功 / 失败重试 五态完整
- **灵活配置**：支持 Anthropic / OpenAI 双协议，也可前端自带 Key（BYOK）
- **丰富导出**：10 种格式一键下载
- **细节体验**：暗色模式、响应式布局（1440 / 1024 / 768 不溢出）

## 快速开始

### 环境要求

- Node.js 20 或更高
- pnpm 10 或更高

### 安装与启动

```bash
pnpm install --frozen-lockfile
pnpm dev          # 默认 http://localhost:8888
```

### 配置模型 Key（前端自带 Key）

1. 打开 http://localhost:8888
2. 点右上角**齿轮图标**或「缺少配置」
3. 填写 DeepSeek 的 Base URL / API Key / 模型名（如 `https://api.deepseek.com`、`sk-...`、`deepseek-chat`）
4. 保存后即可生成（配置存于当前浏览器 localStorage）

## 常见问题

**Q：生成内容能直接用于课堂吗？**
A：生成内容属教学辅助结果，投入真实课堂前请结合课程目标与学情进行**人工审核**。

**Q：Key 存在哪里？安全吗？**
A：BYOK 模式下 Key 只存当前浏览器 localStorage，仅用于调用你填写的模型服务，不上传其它服务器。

**Q：能部署到哪些平台？**
A：当前为**纯前端 + 静态导出**架构，构建产物在 `out/`，可部署 GitHub Pages / 任意静态托管；也可作为静态站部署到 Vercel。
